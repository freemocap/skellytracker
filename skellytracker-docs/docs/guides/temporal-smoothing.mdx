# Temporal Smoothing

Tracking across frames uses temporal state (held in
[`TrackerState`](../core-concepts/tracker-state.mdx)) to stabilize both the
bounding boxes that crop each subject and the keypoints estimated inside them.

## Bounding-box policy

The bounding-box policy controls how the crop for the next frame is derived from
the current detection and keypoints, with smoothing to keep it from jittering or
collapsing.

## Keypoint filtering

Keypoints can be smoothed with filters (e.g. one-euro / Kalman) to reduce
frame-to-frame noise.

## Keypoint reset policy

A reset policy determines when a keypoint detector's temporal state is cleared
(for example when a subject is lost) so tracking recovers cleanly.
