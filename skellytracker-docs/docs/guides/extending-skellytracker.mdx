# Extending skellytracker

You can add a new keypoint detector by subclassing `KeypointDetector` and
registering it:

```python
from skellytracker.core.detectors import KeypointDetector, KEYPOINT_DETECTOR_REGISTRY

class MyDetector(KeypointDetector):
    ...

KEYPOINT_DETECTOR_REGISTRY["my_detector"] = MyDetector
```

Object detectors work the same way via `OBJECT_DETECTOR_REGISTRY`.
