# Choosing a Tracker

Which backend to use depends on what you're tracking and what hardware you have.

| Backend | Tracks | Hardware | Notes |
|---------|--------|----------|-------|
| **MediaPipe** | Body pose, hands, face | CPU (or CoreML on macOS) | Easiest to run; no GPU required |
| **RTMPose (+ YOLOX)** | 133 whole-body keypoints | CPU or GPU (ONNX Runtime) | Highest accuracy; best on GPU |
| **Aruco** | Fiducial markers | CPU | Marker tracking / calibration |
| **Charuco** | Charuco board corners | CPU | Camera calibration |
