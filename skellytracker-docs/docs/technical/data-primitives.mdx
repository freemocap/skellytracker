# Data Primitives

`Keypoints` and `BoundingBox` are the two low-level data primitives everything
else is built on. Callers usually work with [`Observation`](../core-concepts/observations-and-keypoints.mdx);
these are the structures the internals use to hold and pass detection results.

## Keypoints

```python
keypoints.xyz          # (N, 3) float array
keypoints.names        # tuple[str, ...] — the i-th name maps to the i-th row
keypoints.visibility   # (N,) float array
```
