# Detection Stages

A `DetectionStage` is the compositional unit of the pipeline. It binds one
optional `ObjectDetector` and one or more `KeypointDetector`s into a single step,
and can carry **child stages** that operate on its output. The stage tree is what
gives the `Tracker` its hierarchical structure.

## Composing stages

```python
config = TrackerConfig(stages=[
    DetectionStageConfig(
        name="body",
        object_detector=YoloxPersonDetectorConfig(),
        keypoint_detectors=[RTMPoseDetectorConfig()],
    ),
])
```

## Hierarchical nesting

Child stages receive the parent's cropped image and keypoint context, so
face/hand specialization is a structural property of the stage tree rather than
ad-hoc logic inside a detector (e.g. a `body` stage whose crop feeds child
`hands` and `face` stages).
